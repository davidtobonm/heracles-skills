# Heracles

This extension adds the heracles skills: a spec-driven, two-track workflow (design the product and architecture, then plan, build, verify, ship and close sprints).

Start in a repo by asking for the `init` skill. It writes `AGENTS.md`, which explains the workflow, how to run each skill and how to stand in for subagents. Follow `AGENTS.md` in any repo that has one.
