# Sprints

The history of the work, in order: what each sprint planned, decided and delivered. It does not say how the product is today; the living docs do. A closed sprint folder is never edited.

Each sprint is a folder `S<NN>-<slug>/` with `spec.md`, `plan.md` and `log.md`, and `evidence/` when it proves stories.
