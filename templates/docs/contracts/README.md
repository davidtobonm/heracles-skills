# Contracts

What crosses a boundary, one file per boundary. Code cites the contract file, never a sprint. A contract changes only in a sprint task that names it.

| Contract | Boundary | File |
|---|---|---|

Add a row when a new boundary appears, for example `| API | the web app and the server | api.md |`. The first sprint that builds a boundary writes its file. Internal details of a module stay in its code.
